# Yu-Gi-Oh Deck Tracker

A personal deck collection tracker with 56 Yu-Gi-Oh decks, featuring individual deck pages, card tracking, and completion status.

## Features

- **56 Complete Decks**: All decks from your collection with full card lists
- **Tier Filtering**: Filter decks by S/A/B/C/D tier ratings
- **Individual Deck Pages**: Each deck has its own detailed page
- **Card Ownership Tracking**: Check off cards you own
- **Add Custom Cards**: Easily add new cards to any deck
- **Alt Path Support**: Decks with multiple build paths
- **Completion Tracking**: Mark decks as completed
- **Persistent Storage**: All data saved in browser localStorage

## Usage

### Main Page
- View all 56 decks in a grid layout
- Filter by tier (S, A, B, C, D) or status (Active, Consolidated)
- Click any deck to view details
- Check "Mark as completed" to track finished decks

### Deck Detail Pages
- View full main deck and extra deck card lists
- Check off cards you own (green highlight)
- Add custom cards with the "+ Add Card" buttons
- Delete custom cards with the Delete button
- For decks with alt paths, switch between build options

## Deck Collection Highlights

- **S Tier Decks**: Chaos Control, Yugi's Anime Arsenal, Red-Eyes Dragoon, Egyptian God Cards
- **A Tier Decks**: 13+ competitive decks including HERO, Blue-Eyes, Dark Magician, Crystal Beast
- **Consolidated Decks**: 8 decks merged for efficiency (e.g., Burn Damage → Fire Aggression Path B)
- **Alt Path Decks**: 9 decks with multiple build options

## Tech Stack

- Pure HTML/CSS/JavaScript (no frameworks)
- localStorage for persistence
- Responsive design
- Private GitHub repository

## Installation

This is a static website. Simply open `index.html` in any modern web browser.

Or deploy to GitHub Pages for online access.

## Data Persistence

All tracking data is stored in your browser's localStorage:
- Deck completion status
- Card ownership tracking
- Custom cards added to decks

Clear browser data will reset all tracking.
